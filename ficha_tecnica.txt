================================================================================
FICHA TÉCNICA E FUNCIONALIDADES — AGROMIL MARKETPLACE
Plataforma de e-commerce agropecuário (Itu/SP)
================================================================================

1. VISÃO GERAL
--------------------------------------------------------------------------------
Nome:            Agromil Agropecuária & Marketplace
Segmento:        Varejo e atacado de produtos agropecuários, pet shop,
                 jardinagem, ferramentas, irrigação e EPIs.
Público:         Consumidor final (varejo) e empresas/condomínios
                 (Plano Corporativo / atacado).
Objetivo:        Loja virtual com catálogo, carrinho, checkout, área do
                 cliente (fidelidade, pedidos, endereços) e painel admin.

2. STACK TECNOLÓGICO
--------------------------------------------------------------------------------
- Framework:        Next.js (App Router)
- Linguagem:        TypeScript
- UI:               Tailwind CSS + Lucide React (ícones)
- Estado (carrinho): Zustand com persistência em localStorage
- Banco de dados:   PostgreSQL (hospedado no Supabase)
- Acesso a dados:   Supabase REST (supabase-js) em runtime; Prisma para
                    schema/migrations/seed
- Auth:             Supabase Auth (clientes) + bcrypt (admin/modo offline)
- Deploy:           Netlify (build: prisma generate && next build)
- PWA:              Suporte a manifest e instalável (PWAInstaller)
- Conversa:         Chat widget integrado

3. ESTRUTURA DE DADOS (PostgreSQL / Supabase)
--------------------------------------------------------------------------------
Tabelas principais:
- Category             Categorias do catálogo (slug único)
- Product              Produtos (nome, descrição, preço, promo, estoque,
                       unidade, sku, imagens[], ativo, destaque)
- Order                Pedidos (cliente, endereço, pagamento, status, total)
- OrderItem            Itens do pedido (relação flexível com produto:
                       productId aceita NULL ao excluir produto — SET NULL)
- Customer             Clientes (plano varejo ou corporativo)
- LoyaltyTransaction   Pontos de fidelidade por cliente
- AdminUser            Usuários administrativos
- Banner, Coupon, Review, Favorite, PriceHistory, StockAlert, Subscription

Categorias (6):
1. Jardinagem & Vasos        (slug: jardinagem)
2. Rações & Acessórios Pet   (slug: petshop)
3. Agropecuária Geral        (slug: agropecuaria)
4. Ferramentas & Equip.      (slug: ferramentas)
5. Irrigação                 (slug: irrigacao)
6. Vestuário & EPI           (slug: vestuario-epi)

4. ÁREAS E FUNCIONALIDADES — LOJA (CLIENTE)
--------------------------------------------------------------------------------
4.1 Catálogo e Navegação
- Home com Hero Slider (banners rotativos) e vitrine de produtos.
- Categoria por slug (/categoria/[slug]).
- Busca (/busca) com filtros.
- Menu de categorias no topo.

4.2 Produto
- Página de detalhe (/produto/[id]) com galeria, descrição, preço/promo,
  seletor de quantidade e "Adicionar ao Carrinho".
- Modal de detalhe rápido (ProductDetailsModal) a partir dos cards.
- Card de produto (ProductCard) com badge de desconto e botão comprar.
- Produtos relacionados (RelatedProducts) na página do produto.

4.3 Carrinho e Checkout
- Carrinho persistente (Zustand + localStorage) com drawer lateral.
- Adição ao carrinho NÃO redireciona: dispara animação "pop" no botão e
  um toast de confirmação.
- Toast inteligente:
    * Verde "Adicionado ao carrinho!" (1ª vez).
    * Amarelo "Você já adicionou este produto — deseja adicionar mais um?"
      (se já estiver no carrinho), com botão "Ver carrinho".
- Layout do toast responsivo (empilhado e full-width no mobile).
- Checkout (/checkout) com cálculo de subtotal, frete e total.

4.4 Área do Cliente (/minha-conta)  [oculta o menu de categorias]
- Visão Geral (dashboard).
- Meus Pedidos (histórico + repetir pedido).
- Meu Perfil (dados, troca para Plano Corporativo).
- Endereços Salvos.
- Clube Fidelidade:
    * Saldo de pontos (120 pts por pedido ENTREGUE).
    * Níveis: Bronze → Prata (600) → Ouro (1800) → Diamante (3600).
    * Benefícios por nível e barra de progresso.
    * Histórico de pontos (crédito/reverso automático conforme status).

4.5 Conta
- Login / Registro de clientes (Supabase Auth).
- Favoritos (/favoritos) com adicionar tudo ao carrinho.

5. ÁREA ADMINISTRATIVA (/admin)
--------------------------------------------------------------------------------
- Dashboard com métricas e relatórios.
- Produtos:
    * Listagem, novo e editar (ProductForm).
    * Upload de imagens com DRAG-AND-DROP (desktop e mobile).
    * Suporte a MÚLTIPLAS imagens (1ª = capa).
    * No mobile: botão "Tirar Foto na Hora" abre a câmera (capture).
    * Compressão automática de imagem (canvas, max 800px, JPEG 70%).
- Categorias: gerenciamento.
- Pedidos: visualização, alteração de status (gera/reverte pontos de
  fidelidade automaticamente ao marcar ENTREGUE).
- Banners / Hero: slots de slide com presets de imagem.
- Cupons: criação e gestão.
- Avaliações: moderação.
- Relatórios: indicadores de vendas.

6. REGRAS DE NEGÓCIO
--------------------------------------------------------------------------------
- Pontos de fidelidade: +120 ao marcar pedido como ENTREGUE; -120 ao
  reverter de ENTREGUE para outro status.
- Exclusão de produto: permitida mesmo com histórico de pedidos (o
  OrderItem mantém snapshot do nome; productId vira NULL).
- Plano Corporativo: descontos no atacado via perfil do cliente.
- Estoque: botão de compra desabilitado quando stock <= 0 (esgotado).

7. VARIÁVEIS DE AMBIENTE (Netlify)
--------------------------------------------------------------------------------
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
- SUPABASE_SERVICE_ROLE_KEY   (necessária para acesso total via server)
- DATABASE_URL                (Postgres, usada em prisma/migrate/seed)

8. SCRIPTS E MANUTENÇÃO
--------------------------------------------------------------------------------
- Build:            npm run build  (prisma generate && next build)
- Seed (SQL):       scripts/seed-products.sql  (60 produtos reais, 10/cat)
- Migrations:       prisma/migrations/*
- Type-check:       npx tsc --noEmit
- Lint:             npm run lint

9. OBSERVAÇÕES DE IMPLANTAÇÃO
--------------------------------------------------------------------------------
- O app usa Supabase REST em runtime (Prisma mantido p/ schema/migrations).
- Deploy não roda migrations automáticas; aplicar SQL manualmente no
  Supabase quando necessário (ex.: exclusão de produtos, seed).
- Dados sensíveis (senha do banco, service_role) NÃO devem ser commitados.
